# Varun Bajpai — Premium Portfolio

A responsive React + Tailwind CSS portfolio inspired by the approved black/crimson UI concept.

## Run locally

```bash
npm install
npm run dev
```

## Customize before publishing

- Replace `public/avatar.png` with your own stylized avatar PNG (transparent background works best).
- Your supplied resume is included at `public/resume.pdf`; the Download Resume button downloads it.
- Update the email, LinkedIn, GitHub, and project links in `src/App.jsx`.
- Project cards use the supplied NexusAI, EcoTrust, and MentorOwl screenshots as previews.
- Live links are configured for all three projects.

## Stack

React, Vite, Tailwind CSS v4, Lucide React.


Agentic AI toolkit section highlights LangChain, LangGraph, RAG, vector databases, multi-agent workflows, LLM tool calling, and context retrieval.
